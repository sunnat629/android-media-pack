## Prerequisites

- Project **MUST** use `minSdk` 21 or later.
- Project **MUST** use AGP 8.0 or later and Kotlin 1.9 or later.
- Project **MUST NOT** depend on `androidx.media3.*` and `com.google.android.exoplayer2.*` at the same time after migration. Mixed dependencies cause `DuplicateClassException` at merge time.
- If the project ships a public SDK or library with external consumers, **MUST** bump the major version because the package rename is a binary-incompatible change.
- Target **Media3 1.9.0** or later.

## Step 1: plan

1. Locate the current ExoPlayer version. If below `2.19.1`, upgrade to `2.19.1` first, then migrate.
2. Grep the codebase for `com.google.android.exoplayer2` and record the affected file count.
3. Flag call sites that need more than a package rename:
    - `SimpleExoPlayer` (replaced by `ExoPlayer`)
    - `StyledPlayerView` (removed, `PlayerView` uses the styled layout)
    - `MediaSessionCompat` + `MediaSessionConnector` (replaced by `androidx.media3.session.MediaSession`)
    - `PlayerNotificationManager` (removed, notification generated by `MediaSessionService`)
    - `DefaultDrmSessionManager.Builder` on a `MediaSource.Factory` (now through `DefaultDrmSessionManagerProvider`)
    - Custom `setCustomLayout` media button configs (replaced by `setMediaButtonPreferences`)
4. Flag any ProGuard / R8 keep rules that reference `com.google.android.exoplayer2`.


**DO NOT** mix ExoPlayer 2.x and Media3 in the same module.

## Step 3: rewrite package imports

Prefer a scripted rewrite (see `scripts/rewrite-imports.sh`) over manual search-and-replace. Key mappings:

- `com.google.android.exoplayer2.SimpleExoPlayer` to `androidx.media3.exoplayer.ExoPlayer`
- `com.google.android.exoplayer2.Player` to `androidx.media3.common.Player`
- `com.google.android.exoplayer2.ui.StyledPlayerView` to `androidx.media3.ui.PlayerView`
- `com.google.android.exoplayer2.upstream.cache.SimpleCache` to `androidx.media3.datasource.cache.SimpleCache`
- `com.google.android.exoplayer2.ext.mediasession.MediaSessionConnector` removed, use `androidx.media3.session.MediaSession`
- `com.google.android.exoplayer2.ext.cast.CastPlayer` to `androidx.media3.cast.CastPlayer` (rewritten API)

## Step 4: replace SimpleExoPlayer

### RIGHT

```kotlin
import androidx.media3.exoplayer.ExoPlayer
val player = ExoPlayer.Builder(context).build()
```

### WRONG

```kotlin
// WRONG: SimpleExoPlayer no longer exists in Media3
val player = SimpleExoPlayer.Builder(context).build()
```

## Step 5: unify MediaSession inside MediaSessionService

### RIGHT

```kotlin
import androidx.media3.exoplayer.ExoPlayer
import androidx.media3.session.MediaSession
import androidx.media3.session.MediaSessionService

class PlaybackService : MediaSessionService() {

    private lateinit var player: ExoPlayer
    private var mediaSession: MediaSession? = null

    override fun onCreate() {
        super.onCreate()
        player = ExoPlayer.Builder(this).build()
        mediaSession = MediaSession.Builder(this, player).build()
    }

    override fun onGetSession(controllerInfo: MediaSession.ControllerInfo): MediaSession? =
        mediaSession

    override fun onDestroy() {
        mediaSession?.run {
            player.release()
            release()
            mediaSession = null
        }
        super.onDestroy()
    }
}
```

### WRONG

```kotlin
// WRONG: MediaSessionConnector is removed in Media3
val mediaSession = MediaSessionCompat(context, "tag")
val connector = MediaSessionConnector(mediaSession).apply { setPlayer(player) }
```

## Step 6: use setMediaButtonPreferences (Media3 1.9.0)

### RIGHT

```kotlin
import androidx.media3.common.Player
import androidx.media3.session.CommandButton

session.setMediaButtonPreferences(
    listOf(
        CommandButton.Builder(CommandButton.ICON_FAST_FORWARD)
            .setDisplayName(getString(R.string.skip_forward))
            .setPlayerCommand(Player.COMMAND_SEEK_FORWARD)
            .build(),
        CommandButton.Builder(CommandButton.ICON_REWIND)
            .setDisplayName(getString(R.string.skip_backward))
            .setPlayerCommand(Player.COMMAND_SEEK_BACK)
            .build(),
    )
)
```

**DO NOT** keep using `setCustomLayout` with a custom `SessionCommand` just to trigger a built-in player method.

## Step 7: rewire DataSource and DRM

### RIGHT

```kotlin
import androidx.media3.common.C
import androidx.media3.common.MediaItem
import androidx.media3.datasource.DefaultHttpDataSource
import androidx.media3.exoplayer.ExoPlayer
import androidx.media3.exoplayer.drm.DefaultDrmSessionManagerProvider
import androidx.media3.exoplayer.source.DefaultMediaSourceFactory

val httpFactory = DefaultHttpDataSource.Factory()
    .setUserAgent("MyApp/1.0")
    .setConnectTimeoutMs(15_000)

val drmProvider = DefaultDrmSessionManagerProvider().apply {
    setDrmHttpDataSourceFactory(httpFactory)
}

val mediaSourceFactory = DefaultMediaSourceFactory(context)
    .setDataSourceFactory(httpFactory)
    .setDrmSessionManagerProvider(drmProvider)

val player = ExoPlayer.Builder(context)
    .setMediaSourceFactory(mediaSourceFactory)
    .build()
```

### WRONG

```kotlin
// WRONG: this was the ExoPlayer 2.x pattern
val drmSessionManager = DefaultDrmSessionManager.Builder().build(httpMediaDrmCallback)
val factory = HlsMediaSource.Factory(dataSourceFactory).setDrmSessionManager(drmSessionManager)
```

## Step 8: adopt the rewritten CastPlayer (Media3 1.9.0)

### RIGHT

```kotlin
import androidx.media3.cast.CastPlayer
import androidx.media3.exoplayer.ExoPlayer
import androidx.media3.session.MediaSession

val exoPlayer = ExoPlayer.Builder(context).build()
val castPlayer = CastPlayer.Builder(context).setLocalPlayer(exoPlayer).build()
val session = MediaSession.Builder(context, castPlayer).build()
```

**DO NOT** keep the pre-1.9.0 pattern where the app manually swapped the `Player` instance when a Cast device was selected.

## Step 9: update PlayerView and adopt Compose UI

1. Replace every `StyledPlayerView` with `PlayerView`. The styled layout is the default.
2. For Jetpack Compose, **PREFERRED** is the `media3-ui-compose-material3` module over wrapping `PlayerView` in `AndroidView`.

Use `@OptIn(UnstableApi::class)` only at the narrowest scope. **DO NOT** add a global `-opt-in=androidx.media3.common.util.UnstableApi` compiler flag.

## Step 10: adopt simplified ExoPlayer APIs (Media3 1.9.0)

- **Mute and unmute:** use `player.mute()` and `player.unmute()` instead of caching the previous volume manually.
- **Stuck player detection:** listen for `StuckPlayerException` in `Player.Listener.onPlayerError` and surface it in analytics.
- **Wake lock:** wake lock management is default-on. **DO NOT** wrap playback in a manual `PowerManager.WakeLock`.
- **Subtitles:** use the new boolean `selectTextByDefault` on `TrackSelectionParameters`.

## Step 11: update ProGuard / R8 rules

1. Remove every `-keep class com.google.android.exoplayer2.**` rule.
2. Media3 ships consumer ProGuard rules through its AARs.

## Step 12: verify

1. `./gradlew clean :app:assembleDebug` must succeed.
2. `./gradlew lint` must report zero Media3-related warnings.
3. `./gradlew :app:connectedAndroidTest` on devices spanning API 21, 29, and 34+.
4. Confirm no `com.google.android.exoplayer` classes remain:

```bash
./gradlew :app:dependencies | grep -i exoplayer
grep -R "com.google.android.exoplayer2" app/src || echo "clean"
```

## Common pitfalls

- **Manifest service action missing.** Without `androidx.media3.session.MediaSessionService` action, `MediaController.connect` silently fails.
- **Foreground service type.** On API 34+, the service **MUST** declare `android:foregroundServiceType="mediaPlayback"` and hold `FOREGROUND_SERVICE_MEDIA_PLAYBACK`.
- **Mixed dependencies.** A single transitive dependency on `exoplayer2` triggers `DuplicateClassException`.
- **UnstableApi sprinkled everywhere.** If the migration ends with hundreds of `@OptIn` annotations, the code is probably calling `androidx.media3.exoplayer.*` internals where `androidx.media3.common.*` would be stable.
- **Manual wake locks.** Remove any manual wake lock code. Media3 1.9.0 holds them by default.
- **CastPlayer double instancing.** Use `CastPlayer.Builder(context).setLocalPlayer(exoPlayer)`.
- **Manual volume caching for mute.** Replace with `player.mute()` / `player.unmute()`.
